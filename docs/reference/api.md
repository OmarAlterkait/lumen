# API reference

The public names, each with its signature and the first line of its docstring (`help(...)` gives the rest). This page
is generated by `tools/docs/api_reference.py` from the code; do not edit it by hand. Units are m, ns, nm and eV.

## Converting, loading and simulating

| Name | Signature | What it does |
|---|---|---|
| `lumen.convert` | `(source, recipe, out, *, inputs: 'dict \| None' = None, overwrite: 'bool' = False) -> 'Path'` | Convert a GDML file under a recipe into a detector file at ``out``; return its path. |
| `lumen.load` | `(name_or_path, *, sensors: 'str' = 'default', calibration: 'str \| None' = 'nominal', models: 'dict \| None' = None) -> 'Detector'` | Load a detector by path or registered name, with a sensor set and a calibration (see the module docstring). |
| `lumen.simulate` | `(det, source, params=None, *, samples: 'int', seed: 'int', replicas: 'int' = 16, gate=None, chunk: 'int' = 1048576, backend: 'str' = 'auto', wrt=(), controls=None, diagnostics=()) -> 'Light'` | Trace ``samples`` Monte Carlo photons from ``source`` through ``det`` and return the light at each sensor. |

## The detector

| Name | Signature | What it does |
|---|---|---|
| `lumen.api.Detector.params` | `(self)` | Return the resolved parameters (``lumen.Params``). |
| `lumen.api.Detector.sensor_table` | `(self) -> 'dict'` | Return the sensors in the order of ``Light.arrivals``, as {"name", "sensor", "position", "axis"}. |
| `lumen.api.Detector.save_calibration` | `(self, params, name: 'str', directory=None, *, note: 'str' = '') -> 'Path'` | Write the values of ``params`` that differ from this detector's as calibration ``name``; return its path. |
| `lumen.api.Detector.with_responses` | `(self, *responses)` | Return this detector with the parameters of sensor responses (``lumen.response``) added at their defaults. |
| `lumen.api.Detector.digest` | `(...)` | Return the detector file's content digest (a calibration records it as ``detector_digest``). |

## The light

| Name | Signature | What it does |
|---|---|---|
| `lumen.Light` | `(arrivals, arrivals_error, mean_arrival_time, histograms, health, provenance, diagnostics)` | What ``simulate`` returns: per sensor the expected photon arrivals at the sensor (before its model), their Monte Carlo error (over the replicas), the mean arrival time (ns), the group's histograms (``lumen.readout``) and the run's health; ``provenance`` (static) says how it was made. Readout functions take ``(light, params)``. ``diagnostics``: the cells of ``simulate(..., diagnostics=)`` by output name, and "weight_scale" (None without). |

## Readout (after tracking)

| Name | Signature | What it does |
|---|---|---|
| `lumen.readout.pe` | `(light, params)` | Return the expected photoelectrons per sensor (S,). |
| `lumen.readout.pe_error` | `(light, params)` | Return the Monte Carlo error of ``pe`` per sensor (S,), from the spread of its R >= 2 replicas. |
| `lumen.readout.pe_density` | `(light, params) -> 'PEDensity'` | Return the expected photoelectrons per bin of the time nodes' spacing over the gate (dark included). |
| `lumen.readout.expected_waveform` | `(light, params) -> 'Waveform'` | Return the expected waveform (mean and variance per sensor and sample; see the module docstring). |
| `lumen.readout.waveform_nll` | `(w: 'Waveform', data)` | Return the Gaussian negative log-likelihood of measured waveforms (C, n) under the expected waveform. |
| `lumen.readout.expected_hits` | `(light, params) -> 'ExpectedHits'` | Return the expected hits per sensor (see the module docstring). |
| `lumen.readout.hits_nll` | `(e: 'ExpectedHits', data: 'Hits', t_window: 'float' = 1.0)` | Return the negative log-likelihood of measured hits (charge and first-hit time) under the expected hits. |
| `lumen.readout.sample` | `(light, params, *, seed: 'int') -> 'SampledEvent'` | Return one simulated event of the expected light (see the module docstring). |
| `lumen.readout.time_nodes` | `(light, params)` | Return (nodes (S, nt), late (S, 2), early (S, 2)): the expected photoelectrons on the time nodes t0 + j dt. |

## Sources

| Name | Signature | What it does |
|---|---|---|
| `lumen.sources.Point` | `(position, n_photons, lam, spectrum, direction, time)` | Photons from ``position`` (m) at ``time`` (ns), weights summing in expectation to ``n_photons``. |
| `lumen.sources.CherenkovSegment` | `(material, start, direction, length, beta, charge, time, lam_min, lam_max)` | A charge ``charge`` (e) from ``start`` (m) along the unit ``direction`` for ``length`` (m) at ``beta``, at ``start`` at ``time`` (ns), in ``material``; its light on [lam_min, lam_max] (nm). |
| `lumen.sources.ScintillationPoint` | `(material, geant4, shares, proposals, position, energy, time)` | ``energy`` (MeV) deposited at ``position`` (m) at ``time`` (ns) in ``material``; build it with ``of``. |
| `lumen.sources.ScintillationSegment` | `(material, geant4, shares, proposals, start, end, t_start, t_end, energy, birks)` | A charged step from ``start`` (time ``t_start``) to ``end`` (``t_end``) depositing ``energy`` (MeV). |
| `lumen.sources.Geant4Steps` | `(material, geant4, shares, proposals, start, end, t_start, t_end, beta_start, beta_end, charge, edep, step_length, birks, lam_min, lam_max, light)` | A step dump's light (``light``: "cherenkov" or "scintillation") in ``material``; build it with ``of``. |
| `lumen.sources.FromArrays` | `(x, d, t, lam, w, polarisation, drawn, dlogp)` | Photons from arrays (see the module docstring); emits rows first_id .. first_id + n - 1. |

## Extending lumen

| Name | Signature | What it does |
|---|---|---|
| `lumen.Param` | `(unit, range, shape, default, moves, method)` | A parameter an extension declares: its unit, allowed range, shape, default and whether it moves the light. |
| `lumen.source` | `(params: 'dict \| None' = None, density: 'str' = 'isotropic', name: 'str \| None' = None)` | Return a decorator making ``f(v, key, n) -> Photons`` a source (see the module docstring). |
| `lumen.response` | `(group: 'str', params: 'dict \| None' = None, name: 'str \| None' = None)` | Return a decorator making ``f(h, v)`` a sensor response of ``group`` (see the module docstring). |
| `lumen.medium_model` | `(name: 'str', params: 'dict \| None' = None)` | Return a decorator registering ``f(material, base) -> MediumSpec`` as the medium model ``name``. |
| `lumen.surface_model` | `(name: 'str', params: 'dict \| None' = None, detects: 'bool' = False)` | Return a decorator registering ``f(surface, base) -> SurfaceType`` as the surface model ``name``. |

### `Light` fields

| Field | What |
|---|---|
| `arrivals` | expected photons counted at each sensor, before its sensor model (S,) |
| `arrivals_error` | their Monte Carlo standard error, from the replicas (S,) |
| `mean_arrival_time` | the arrivals-weighted mean arrival time after emission, ns (S,) |
| `histograms` | the modelled group's histograms: wavelength, hit angle, time (None without one) |
| `health` | what happened to the light that was not counted (docs/reference/errors.md, Health) |
| `provenance` | how the result was made: seed, samples, replicas, chunk, backend, detector, wrt |
| `diagnostics` | what the diagnostics passed to simulate recorded (None without) |
