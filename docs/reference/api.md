# API reference

The public names, each with its signature and the first line of its docstring (`help(...)` gives the rest). This page
is generated by `tools/docs/api_reference.py` from the code; do not edit it by hand. Units are m, ns, nm and eV.

## Converting, loading and simulating

| Name | Signature | What it does |
|---|---|---|
| `lumen.convert` | `(source, out, *, recipe=None, data=None, inputs: 'dict \| None' = None, overwrite: 'bool' = False) -> 'Path'` | Convert a detector into a detector file at ``out``; return its path. |
| `lumen.load` | `(path, *, calibration: 'str' = 'nominal', parts: 'dict \| None' = None, responses=(), precision: 'str \| None' = None) -> 'Detector'` | Load the detector file at ``path`` (a ``.lumen`` directory) with a calibration. |
| `lumen.simulate` | `(det, source, params=None, *, samples: 'int \| None' = None, seed: 'int', gate=None, events: 'int \| None' = None, reference=None, controls=None, backend: 'str' = 'auto', chunk: 'int \| None' = None, records: 'int \| None' = None, diagnostics=(), truth=None) -> 'Light'` | Trace ``samples`` Monte Carlo photons from ``source`` through ``det`` and return the light at each sensor. |

## The detector

| Name | Signature | What it does |
|---|---|---|
| `lumen.api.Detector.params` | `(self)` | Return the resolved parameters (``lumen.Params``). |
| `lumen.api.Detector.sensor_table` | `(self) -> 'SensorTable'` | Return the sensors in the order of ``Light.arrivals`` (``SensorTable``: placed volume, sensor entry, world position (m), axis, and the id map's columns). |
| `lumen.api.Detector.save_calibration` | `(self, params, name: 'str', directory=None, *, note: 'str' = '') -> 'Path'` | Write the values of ``params`` that differ from the detector file's own as calibration ``name``; return its path. |
| `lumen.api.Detector.digest` | `(...)` | Return the detector's digest: its file's content and its sensor set (groups, value sets, id map); a calibration records it as ``detector_digest``. |

## The light

| Name | Signature | What it does |
|---|---|---|
| `lumen.Light` | `(arrivals, arrivals_error, mean_arrival_time, health, provenance, diagnostics, groups, truth)` | What ``simulate`` returns: per sensor the expected photon arrivals at the sensor (before its model), their Monte Carlo error (from their per-photon second moment, ``lumen.readout.grid.moment_error``), the mean arrival time (ns), the histograms (``lumen.readout``) of each group with a sensor model and the run's health; ``provenance`` (static) says how it was made (the seed, samples, chunk, backend, detector, calibration, the step's controls, each group's gate, and the loop run: "fast" (the diffusion jump, ``lumen.transport.fastpath``), or "exact (diagnostics)" for a probe run the jump cannot serve). Readout functions take ``(light.group(name), params)``. ``groups``: {group: Histograms} of every modelled group (None without). ``diagnostics``: the diagnostics' cells by output name (``simulate(..., diagnostics=)``; None without). ``truth``: the truth rows (``simulate(..., truth=)``: ``lumen.readout.TruthHits``; None without). With ``simulate(..., events=E)`` every array but the health has a leading event axis (E, ...): ``event(e)`` is event e's Light. |

## Readout (after tracking)

| Name | Signature | What it does |
|---|---|---|
| `lumen.readout.pe` | `(light, params)` | Return the expected photoelectrons per sensor: of a group's Histograms (its sensors), or of a Light (every sensor of the detector, in ``Light.arrivals``' order: each modelled group's at its sensors, 0 at a sensor of no modelled group). |
| `lumen.readout.pe_error` | `(light)` | Return the Monte Carlo error of ``pe`` per sensor at the values the run was given (``simulate``'s ``params``): of a group's Histograms (its sensors), or of a Light (every sensor, as ``pe``; 0 at a sensor of no modelled group). |
| `lumen.readout.pe_density` | `(light, params, *, dark: 'bool' = True) -> 'PEDensity'` | Return the expected photoelectron time profile: photoelectrons per bin of the time nodes' spacing over the gate, after the whole time response (each delay cell's delay, the time spread, the transit offset), with the dark counts (``dark=False``: the light's alone; its bins sum to ``pe`` within the gate). |
| `lumen.readout.expected_waveform` | `(light, params) -> 'Waveform'` | Return the expected waveform (mean and variance per sensor and sample; see the module docstring). |
| `lumen.readout.waveform_nll` | `(w: 'Waveform', data)` | Return the Gaussian negative log-likelihood of measured waveforms (C, n) under the expected waveform. |
| `lumen.readout.expected_hits` | `(light, params) -> 'ExpectedHits'` | Return the expected hits per sensor (see the module docstring). |
| `lumen.readout.hits_nll` | `(e: 'ExpectedHits', data: 'Hits', t_window: 'float' = 1.0)` | Return the negative log-likelihood of a measured hit list under the expected hits (the module docstring). |
| `lumen.readout.sample` | `(light, params, *, seed: 'int') -> 'SampledEvent'` | Return one simulated event of the expected light (see the module docstring). |
| `lumen.readout.Truth` | `(keep, angle, position)` | What truth rows a run keeps: ``keep`` "detected" (default) or "absorbed" (every cathode absorption, with its ``detected`` flag); ``angle``, ``position``: the hit angle and the hit point columns. |
| `lumen.readout.TruthHits` | `(photon, label, sensor, time, detected, angle, position, n_photons, groups, group_of)` | The truth rows of a run (see the module docstring): numpy columns, one row per photon, in photon order. |

## Sources

| Name | Signature | What it does |
|---|---|---|
| `lumen.sources.Point` | `(label, position, n_photons, lam, spectrum, direction, time)` | Photons from ``position`` (m) at ``time`` (ns), weights summing in expectation to ``n_photons``. |
| `lumen.sources.CherenkovSegment` | `(label, material, start, direction, length, beta, charge, time)` | A charge ``charge`` (e) from ``start`` (m) along the unit ``direction`` for ``length`` (m) at ``beta``, at ``start`` at ``time`` (ns), in ``material``; its light over the RINDEX table's span. |
| `lumen.sources.ScintillationPoint` | `(label, material, share_keys, components, rises, position, energy, time)` | ``energy`` (MeV) deposited at ``position`` (m) at ``time`` (ns) in ``material``; build it with ``of``. |
| `lumen.sources.ScintillationSegment` | `(label, material, share_keys, components, rises, start, end, t_start, t_end, energy, birks)` | A charged step from ``start`` (time ``t_start``) to ``end`` (``t_end``) depositing ``energy`` (MeV). |
| `lumen.sources.CherenkovSteps` | `(label, material, start, end, t_start, t_end, beta_start, beta_end, charge, step_length)` | A step dump's Cherenkov light in ``material`` (see the module docstring): ``start``, ``end`` (n, 3) m, ``t_start``, ``t_end`` (n,) ns, ``beta_start``, ``beta_end`` (n,), ``charge`` (n,) e, ``step_length`` (n,) m or None; its light over the RINDEX table's span. |
| `lumen.sources.ScintillationSteps` | `(label, material, share_keys, components, rises, start, end, t_start, t_end, edep, step_length, birks)` | A step dump's scintillation light in ``material`` (see the module docstring): ``start``, ``end`` (n, 3) m, ``t_start``, ``t_end`` (n,) ns, ``edep`` (n,) MeV, ``step_length`` (n,) m or None, Birks' ``birks`` (m/MeV); build it with ``of``. |
| `lumen.sources.FromArrays` | `(label, position, direction, time, lam, weight, polarisation)` | Photons from arrays (see the module docstring); emits rows first_id .. first_id + n - 1. |

### `Light` fields

| Field | What |
|---|---|
| `arrivals` | expected photons counted at each sensor, before its sensor model (S,) |
| `arrivals_error` | their Monte Carlo standard error, from each sensor's per-photon second moment (S,) |
| `mean_arrival_time` | the arrivals-weighted mean arrival time after emission, ns (S,) |
| `health` | what happened to the light that was not counted (docs/reference/errors.md, Health) |
| `provenance` | how the result was made: seed, samples, chunk, backend, detector, controls |
| `diagnostics` | what simulate(..., diagnostics=) recorded, by output name (None without) |
| `groups` | {group: histograms} of every modelled sensor group (None without); light.group(name) |
| `truth` | the truth rows of simulate(..., truth=): one per detected photon (None without) |
